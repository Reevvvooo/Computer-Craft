## ComputerCraft / CC: Tweaked Referenzen

Bevor du beim Schreiben oder Debuggen von ComputerCraft-Lua-Code (`cc-scripts/`) im Web suchst, prüfe zuerst die lokalen Referenzen:

1. `.information/cc-tweaked-1.21.1-reference.md` — die CC: Tweaked API-Referenz (Peripherals, Turtle-API, `os`/`term`/`fs`-APIs, Events, etc.).
2. `.information/` generell — hier können weitere projektspezifische Notizen und Referenzen liegen.
3. Es gibt keine für dich zugängliche lua-Umgebung, in der du deinen Code ausführen oder testen kannst

Nutze eine Websuche für ComputerCraft-Themen nur, wenn die benötigte Information dort nachweislich fehlt.
